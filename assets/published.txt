Platform   : Windows | macOS | Linux
Author     : Anurag Panda (github.com/anurag-panda-dev)
Published  : 2026-10-09

DESCRIPTION
-----------
A production-ready, Playwright-based Instagram OSINT toolkit that drives your own
logged-in Chrome via the Chrome DevTools Protocol (CDP) — no API keys, nothing
leaves your machine.

Harvests profiles, posts, comment threads (with replies), followers and following
lists into JSON / CSV / SQLite, downloads every post and carousel image at full
resolution as timestamped PNGs, computes engagement, posting-pattern, network and
bio-intel analytics, and serves it all in a live local dashboard. Ships with a
single PowerShell entry point, resume caching, proxy support, Docker and tests.
